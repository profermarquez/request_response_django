Explorador de Django Request & Response

Este sitio educativo te guía a través de los componentes principales del manejo de solicitudes (request) y respuestas (response) en Django.

  • HttpRequest objects: Muestra los atributos más comunes disponibles en una solicitud entrante.
  • Attributes set by application code: Ejemplo de cómo tu propia vista puede agregar atributos al request.
  • Attributes set by middleware: Ejemplo de cómo un middleware puede agregar datos al request.
  • QueryDict objects: Muestra los datos que vienen en GET y POST y cómo Django los representa.
  • HttpResponse objects: Muestra una respuesta HTTP básica con texto plano.
  • HttpRequest.is_secure(): Verifica si la conexión es segura (HTTPS).
  • HttpResponse subclasses: Agrega cabeceras personalizadas a una respuesta.
  • JsonResponse: Ejemplo de cómo retornar datos en formato JSON.
  • Vista GET/POST combinada (formulario demo): Demuestra cómo manejar ambos métodos en una misma vista.
  • StreamingHttpResponse: Muestra cómo enviar datos por partes (streaming).
  • Handling disconnects: Explicación teórica sobre cómo manejar desconexiones del cliente.
  • FileResponse: Descarga un archivo como respuesta.
  • HttpResponseBase: Describe la clase base de todas las respuestas.

Este proyecto fue diseñado con fines educativos para ayudar a entender cómo Django maneja la interacción cliente-servidor.
